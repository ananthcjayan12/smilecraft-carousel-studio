# Harbour Gum Dental demo collection

Fictional Melbourne clinic, Australian English. Created with the built-in image_gen tool in the supplied deep-teal/aqua reference style. All people and clinic scenes are AI-generated.

- Five carousel slides and two feed posts: 1080 × 1350 WebP.
- Two stories: 1080 × 1920 WebP.
- Standalone tooth/eucalyptus logo: 900 × 300 WebP.
- WebP quality 82 (logo 88), compression effort 6.
- `prompts.json` records generation prompts; `manifest.json` records the reusable asset catalogue.
- `harbour-gum-demo-pack.zip` contains all ten WebP files and the manifest.

Used on `/samples/`, `/dental-demo/`, and the landing-page artwork/phone walkthrough. Example copy is illustrative. No real practice contact details are included.
